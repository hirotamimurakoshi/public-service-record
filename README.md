# Hirotami Murakoshi — Public Service & Policy Record

日本語：村越祐民｜国政・市政での仕事

## Purpose

This is a standalone, static GitHub Pages **project site** for documented public-policy and municipal-government work. It is separate from the existing litigation archive at `https://hirotamimurakoshi.github.io/`.

## Intended repository and URL

- Repository: `hirotamimurakoshi/public-service-record`
- Public site: `https://hirotamimurakoshi.github.io/public-service-record/`
- **Do not** replace the root user site or its `index.html` yet.

## Publish

1. GitHub > New repository > Name: `public-service-record` > Public > Create repository.
2. Upload the **contents** of this folder into the repository root. Preserve directories.
3. GitHub repository > Settings > Pages > Build and deployment > Source: `Deploy from a branch` > Branch `main`, folder `/ (root)` > Save.
4. Confirm that the published URL above opens all links, including CSS and nested pages.
5. Only after checking publication, link from LinkedIn or note. Keep the existing litigation root URL unchanged.

No build tools, framework, third-party JavaScript, remote fonts, tracking pixels or API keys are needed. Pages have relative internal links so the site can be hosted under a project-path prefix.

## Editorial rules

- Separate announcements, legislative drafts, implemented policy and measured outcomes.
- Distinguish independent journalism, official documents, vendor case studies and personal commentary.
- The childcare waiting-list reduction spans before and after the 2018 mayoral term; do not claim exclusive credit.
- Capital-sentencing legislation was prepared, but not established as introduced or enacted.
- Recheck all external links and factual details before public release.
- Source articles remain with original publishers; no copied article text or images are included.

## Later migration

Once the new site is mature, decide whether to move it to the root user site and move litigation to `/litigation/` with carefully planned redirects or transitional notices. Do not change URLs without checking old linked PDFs, anchors and external backlinks.
